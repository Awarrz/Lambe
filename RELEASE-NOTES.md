# Lambe 0.9.6 Open alpha

Created and developed by André I. Ben, Lambe Labs.

Download **Lambe-0.9.6-Windows-x64.zip** for Windows or **Lambe-0.9.6-Android.apk** for Android. Windows users should extract the complete ZIP and open Lambe.exe. Android users should install the APK. Fonts and modes are included; Flutter is not needed.

This release includes Arabic · Arabizi (McGovern-based), available in Writing mode from the first launch. Digit letters such as 3 and 7 remain letters when Tengwar numerals is switched. Prefix actual numbers with a backslash, for example `\2026`. The Arabic profile can be duplicated and edited like other modes.

Windows keeps saved definitions in the modes folder beside the app when that folder is writable, with an app-data fallback. Android uses private app storage. The user guide now includes installation, updating and Arabizi conventions. Contextual R also works in copied reference modes whose original map relies on the R rule.

Blank inputs, full-width Windows layout, ordinary caret navigation, English combination fixes, final-S curl adjustments, newlines, image export, independent mode duplication and invisible associations are retained.

Export custom modes before moving or replacing your installation. Saved source compositions and unsaved font work do not reopen automatically. Include the exact input, selected mode, device and expected result in feedback.
